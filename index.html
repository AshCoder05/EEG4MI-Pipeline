FBCSP Band Decomposition
6 overlapping bandpass filters spanning the sensorimotor rhythm range (8–30 Hz). Each filter is a causal IIR Butterworth order 4. The overlap between bands (e.g. 10–14 and 12–16) improves spatial robustness.
Filter bank — 6 FBCSP bands
Why these bands? They target alpha (8–12), low-beta (12–16), mid-beta (14–20), and upper-beta/gamma (18–30). The overlapping design means each ERD dip is captured by multiple filters.

CSP Spatial Filters
Common Spatial Patterns finds projection vectors maximizing the variance ratio between LEFT and RIGHT MI classes. The first and last CSP components should maximally separate the classes. Topomaps show the spatial distribution — C3 activity for left MI, C4 for right MI.
CSP objective (mathematical)
maxw wTΣ₁w / wTΣ₂w
Generalized eigenvalue problem · Σ = covariance matrix
Geometric interpretation: CSP finds the axis along which LEFT and RIGHT covariance ellipsoids are maximally separated. This is the covariance geometry visualization the PDF describes.

Feature Space (PCA scatter)
FBCSP extracts log-variance features from each filtered band × CSP component. These are concatenated into a feature vector and projected to 2D with PCA for visualization. Well-separated clusters confirm the pipeline is working.
Stage 1: REST vs INTENT
PCA 2D projection
Good separation = clean BCI. The two clusters should be distinct. Overlap predicts misclassification.
Stage 2: LEFT vs RIGHT MI
PCA 2D projection
L/R separation is harder than REST/INTENT. Some overlap is expected. Fisher's LDA will draw the optimal boundary.
LDA Decision Boundary
Linear Discriminant Analysis projects features onto the axis maximizing between-class / within-class variance ratio. The decision boundary is a hyperplane where posterior P(class₁) = P(class₂) = 0.5. In 2D this is a line.
